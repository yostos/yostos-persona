[8月13日の千葉の大雨](@/blog/2026/08/chiba-heavy-rain/index.md)による影響はまだまだ各所に残っていますが、路上の自動車などはほぼ撤去されました。
個人的に最も懸念しているのは
[国立研究開発法人 量子科学技術研究開発機構](https://www.qst.go.jp)（以下、QST）からの放射性廃液漏えいです。

「環境への影響はない」という一言で終わってしまいそうな気配があるので、事象から1週間が経った時点で、何がどこまで分かっているのかを整理しておきます。

## 流出までの経緯

QSTの千葉地区は、稲毛区穴川にあります。京葉道路の穴川インターのすぐ脇で、周囲は住宅とスーパーと学校です。

漏えいが起きたのは、そのキャンパスにあるポジトロン棟です。以下は、QSTが8月15日に公表したプレスリリースと、原子力規制庁が8月17日に公表した「量子科学技術研究開発機構からの報告の概要」および別添図にもとづく経緯です。どちらに書かれている内容かを括弧で示します。

なお、タンクの容量や高さは、QSTのプレスリリースにも原子力規制庁の資料にも記載がありません。基数が3基であることは、原子力規制庁が公表した別添図に「廃液受槽タンク（3基）」と明記されています。

## 本当に環境への影響はないのか

### QSTの報告と「影響なし」の判断

QSTの結論は、「本件による環境への影響はない」「今後の拡大の恐れはない」というものです。この結論は、性質のまったく違う3つの根拠で支えられています。

| 根拠 | 内容                                                                                                                                          | 種別 | 何を証明したか                                                   |
| ---- | :-------------------------------------------------------------------------------------------------------------------------------------------- | ---- | :--------------------------------------------------------------- |
| A    | 8月13日時点でタンクに貯留されていたRIの残存放射能を使用記録から算出した結果、排出濃度基準値以下だった                                         | 計算 | 机上計算では流出元の液が基準値以下だったこと                     |
| B    | 8月14日にドライエリアの水を採取分析し、放射性物質が検出濃度限度以下、排出濃度基準値以下であることを確認                                       | 実測 | 大雨の翌日には、流出経路の入口の水に放射能がなかったこと         |
| C    | 8月14日10時00分頃に施設周辺の空間線量率を測定し、自然放射線レベルであることを確認。敷地境界のモニタリングポストにも平常時からの有意な変化なし | 実測 | 大雨の翌日、敷地周辺の空間線量率が自然放射線と同じ水準だったこと |

3つ並んでいると多重に確認したように読めますが、よく読むと確認できているのは以下だけです。

- (A) 机上計算では流出液の放射線量は排出濃度基準値以下だった
- (B) 大雨の翌日に流出経路入り口では放射能が検出されなかった
- (C) 大雨の翌日QST敷地内の放射線量は通常と同じ水準だった

QSTからの流出が環境に影響するものだったのか実際に測定されたものは1つもありません。

### QSTの報告の問題点

つまり、QSTの報告ではQSTからの流出が環境に影響するものか何も証明されていないのではないかと考えます。

まず(A)「机上計算では流出液の放射線量は排出濃度基準値以下」です。
これはタンクに何がどれだけ入っていたかを使用記録から逆算したもので、実際にタンクの液を採取して測ったという記載はありません。使用記録の正確さ、タンクへの実際の投入量、過去分の減衰計算に依存しており、第三者による突合も行われていません。そもそも扉が水圧で開くという想定外の事象が起きた施設で、貯留量の管理だけは想定どおりだったと言えるのかどうか、実測で裏を取らなければ確認できません。使用記録による在庫管理そのものは、RI規制法のもとでの標準的なやり方です。問題は、想定外のことが起きた後もそれだけで済ませていることです。

次に(B)「大雨の翌日に流出経路入り口では放射能が未検出」です。
流出しているのですから、流出経路入り口で検出されなかったことが「流出が問題となる量でなかった」証明にはなりません。一般排水との合流点、排水枡、放流先といった下流側での測定は何も行われていません。
さらに問題なのは採取のタイミングです。大雨は8月13日の夜、採取は8月14日でした。ポジトロン棟で使う核種は半減期が分や時間の単位のものが多く、翌日には大きく減ってしまいます。検出されなかったのが、流出しなかったからなのか、測る前に消えたからなのか、この測定では区別がつきません。

下表の核種は、QSTが公表している千葉地区の研究内容から想定される範囲です。当該タンクの実際の内容物が公表されたわけではありません。

| 核種          |   半減期 | 8月14日の採取時点          |
| ------------- | -------: | -------------------------- |
| O-15          |    2.0分 | 検出不能                   |
| N-13          |   10.0分 | 検出不能                   |
| C-11          |   20.4分 | 検出不能                   |
| F-18          |  109.8分 | 初期量が不明で判定できない |
| Cu-64         | 12.7時間 | 検出可能                   |
| Zr-89         | 78.4時間 | 検出可能                   |
| I-124         |   4.18日 | 検出可能                   |
| Ge-68 / Ga-68 |    271日 | 検出可能                   |

最後に(C)「大雨の翌日QST敷地内の放射線量は通常と同じ水準だった」です。
空間線量率の測定とモニタリングポストが見ているのは、いずれも空気中のγ線です。排水に混じった微量の液体放出を捉える感度はありません。原理的に本件の証拠にはならず、「自然放射線レベルだった」ことは「流出がなかった」ことを示しません。補強材料にすらならない項目が、根拠の1つとして並んでいます。

こうして見ていくと、QSTが根拠として発表している内容は何も「環境への影響はない」の証明となっていません。

更に問題なのは、流出があったとされるタンクをまだ誰も見ていない可能性が高いことです。

水没したという判断すら浸水状況からの推定です。こうした中で「環境への影響がない」と発表するのは、このような機関として早計にすぎるように思います。

念のために書いておくと、実際に環境への影響がなかった可能性は高いと思っています。濃度から考えて、そう外れた見込みではないでしょう。ただし現時点の公表情報では、第三者がその結論を独立に検証する材料が揃っていません。「影響はない」は、QSTの内部記録と計算を信頼することが前提の主張にとどまっています。

## 千葉市との環境保全協定の問題点

ここで、住宅地の真ん中にこうした施設がある経緯にも触れておきます。

QST千葉地区は、1957年7月設立の放射線医学総合研究所のキャンパスが前身です。設立の直接の契機は、1954年のビキニ環礁での水爆実験と第五福竜丸の被災でした。原子力の推進側ではなく、被曝の被害を調べる側の研究所として作られています。

穴川に庁舎が建って業務が始まったのは1959年でした。稲毛海岸を埋め立てて宅地を開発する稲毛海浜ニュータウン事業の着手は、1969年です。これが、住宅地の真ん中にこのような施設がある理由です。

周囲が住宅地に変わっていく過程で、施設側と規制当局と自治体が都市化した環境に見合った安全対策と住民への説明を行なっているはずです。

その観点で気になるのが、千葉市が公表している「[環境の保全に関する協定](https://www.city.chiba.jp/kankyo/kankyohozen/hozen/kankyohozennkyotei.html)」の一覧です。

| 項目       | 内容                                     |
| ---------- | :--------------------------------------- |
| 事業者名   | 国立研究開発法人量子科学技術研究開発機構 |
| 所在地     | 稲毛区穴川4-9-1                          |
| 業種       | 研究所                                   |
| 締結年月日 | 平成27年4月1日                           |
| 協定対象   | 大気、地質、騒音、振動、地盤沈下、悪臭   |

業種は「研究所」とだけ記載され、協定の対象に放射性物質と放射線は入っていません。

これが意味するところは小さくありません。前章で下流側の測定が公表されていないと書きましたが、それを千葉市が独自に求める根拠は、少なくともこの協定の対象範囲からは出てきません。今回、QSTから県・市への連絡は行われていますが、それは法令報告と任意の情報提供の組み合わせです。

ただし、協定に入ってさえいれば千葉市が調べられたかというと、そうでもありません。水質汚濁防止法と下水道法は放射性物質を適用除外しており、RI規制法にも自治体の立入検査の規定はありません。放射性物質の規制は原子力規制委員会に一元化されていて、自治体の関与は任意の協定と情報提供にとどまる構造です。協定の対象に放射性物質がないことは、その構造の写し絵にすぎません。

国有地へ静かに置かれた研究所の周囲に、後から住宅地が広がりました。その間、住民の側が持つ検証の手段は積み上がってこなかったのではないか。今回の事案が投げかけているのは、結局この問いです。

## QSTという組織の問題点

もう一点、この法人がどう生まれたかも見ておく必要があります。

QSTが発足したのは2016年4月1日ですが、前述のように前身である国立研究開発法人放射線医学総合研究所法を改正して法人の名称と業務範囲を変え、日本原子力研究開発機構の核融合研究開発部門と量子ビーム応用研究部門の一部を統合したものです。放医研という法人格がそのまま存続し、そこに原子力機構の一部が移ってきた形になります。

では、なぜその再編が必要だったのか。政府の公式な提案理由は「量子科学技術の重要性が高まる中で研究を集約する」という前向きなものでしたが、実際の発端は別のところにあります。2015年6月30日の参議院文教科学委員会で、文部科学省の研究開発局長はこう説明しています。

> このため、平成二十四年末に発覚いたしました「もんじゅ」の保守管理不備や、平成二十五年五月のＪ－ＰＡＲＣの放射性物質漏えい事故を発端としまして、これまでの原子力二法人統合の問題点も踏まえつつ、安全を最優先とした業務運営や組織体制の在り方について抜本的に見直すとともに

もんじゅの約1万件に及ぶ点検漏れと、J-PARCハドロン実験施設の放射性物質漏えい事故。この2つを受けて原子力機構を核燃料サイクル研究に重点化する方針が固まり、量子ビームと核融合が外に出されました。その受け皿になったのが放医研です。不祥事を起こした部門が異動してきた訳ではありませんが、その組織の一部を引き受けて生まれた法人が10年後に自らのキャンパスで放射性廃液の漏えいを起こしたことになります。

問題はそのような経緯で組織改編を議論をしながら、受け皿である千葉キャンパスについては何も議論されていないことです。国会会議録を確認した限り、衆参どちらの審議でも、千葉の施設の安全管理体制、老朽化、放射性廃棄物や廃液の管理に対する具体的な言及は見当たりません。組織をどう束ねるかは詳しく議論されましたが、束ねられる側の建物と設備がどういう状態かは、国会の視野に入っていませんでした。

今回、豪雨で地下貯留室の扉が水圧で開いたという事象は、その延長線上にあるように思います。

## 今後の対応について

QSTの詳細報告書は、この種の法令報告事象では提出まで数週間から1か月程度を要するのが通例です。次の情報は9月以降になる可能性が高いでしょう。事後検証は、半減期の問題で事実上不可能です。

報告書が出たときに確認したいのは、次の4点です。

- 核種ごとの放射能量（Bq）が示されているか。「検出濃度限度以下」は核種を特定しなければ評価できない。告示濃度限度は核種によって3桁以上異なる
- 漏えい量の推定値（L）と、その算出根拠が示されているか
- 測定地点が図示され、下流側が含まれているか
- 各測定の検出下限値と、対応する告示濃度限度が併記されているか

これらが欠けたまま「影響なし」で結ばれている場合、報告書としては検証に耐える内容ではありません。加えて、タンク残液の実測値と使用記録からの算出値を突合したマスバランスの検証があるかどうかも見どころです。ここが合わなければ根拠Aは丸ごと崩れます。

## まとめ

流出したかどうかは、QST自身が「可能性は否定できない」と認めています。争点は流出の有無ではなく、量と核種、そして環境中での挙動です。

公表された根拠のうち、実測による裏づけがあるのは長半減期核種の1地点だけでした。短半減期核種については計算しかなく、実測はすでに物理的に不可能な時期に入っています。下流側の測定結果と定量値は公表されていません。

制度の側を見れば、放射性物質の規制は国に一元化されており、自治体が独自に調べる手段は制度として用意されていません。千葉市との環境保全協定に放射性物質が入っていないのは、その写し絵です。組織の側を見れば、他組織の不祥事を契機に生まれた法人でありながら、その受け皿となった千葉キャンパスの施設管理は、統合を決めた国会審議で一度も俎上に載っていません。

繰り返しますが、実際に影響がなかった可能性は高いと考えています。それでも、住宅地のただ中にある放射性物質取扱施設で起きたことを、その施設の内部記録と計算だけで納得させられる状態を、健全とは思いません。9月に出るであろう報告書で、核種名と数字が示されることを期待しています。
