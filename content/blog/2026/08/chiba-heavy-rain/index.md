2026年8月13日の夜、千葉県で記録的な大雨となり、県内の広い範囲に警戒レベル5の大雨特別警報が発表されました。以下は22時55分時点でわかっている状況です。事態は動いている最中なので、この記事はその時点の記録として読んでください。

## 気象庁・国土交通省の発表

13日夜の気象庁・国土交通省の主な動きを時系列で並べます。

| 時刻     | できごと                                                                             |
| :------- | :----------------------------------------------------------------------------------- |
| 19時30分 | 千葉市など14市にレベル5大雨特別警報を発表                                            |
| 20時     | 茨城・埼玉・千葉の3県12市町、17万6988人に避難指示（消防庁まとめ）                    |

| 22時     | 南房総市付近で記録的な大雨。9分後には市原市付近と館山市付近にも記録的短時間大雨情報  |
| 22時15分 | 茂原市と大網白里市を追加し、大雨特別警報の対象が18市に                               |

発表資料の要点は次の通りです。

- これまでに経験したことのないような大雨である。特に土砂災害警戒区域や浸水想定区域では何らかの災害がすでに発生している可能性が極めて高い
- 命の危険が迫っているため直ちに身の安全を確保しなければならない状況
- 崖や沢から少しでも離れた建物や、浸水しにくい高い場所へ移動する
- 特別警報の発表を待つのでは手遅れになるため、市町村がすでに出している避難情報に直ちに従う

## 千葉市の状況

私が住んでいる千葉市でも、雨の降り方と雷が尋常ではありませんでした。
千葉市では19時前までの1時間に115ミリが降り、**統計を取り始めてから最も多い雨量**となっています。

気象庁の特別警報を受けて、千葉市も緊急・防災メールで避難情報を段階的に出しています。
発信元はいずれも、市の防災を所管する千葉市総合政策局危機管理部危機管理課です。

| :------- | :------------------------------------------------------------------------------------------------- |
| 19時31分 | 気象警報・注意報。市内にレベル5大雨特別警報、レベル4土砂災害危険警報、雷注意報が発表されたと伝える |
| 19時55分 | 【警戒レベル５】大雨特別警報に係る避難指示。土砂災害警戒区域、土砂災害特別警戒区域、洪水区域が対象 |
| 22時03分 | 【警戒レベル５】土砂災害特別警報に係る緊急安全確保。土砂災害警戒区域と土砂災害特別警戒区域が対象   |

多言語支援センターの情報は、千葉市国際交流協会のサイトで確認できます。

## 被害と今後

今起こっている豪雨の原因は、列島の北側にある高気圧の周辺から暖かく湿った空気が流れ込み、上空の寒気とぶつかって大気の状態が非常に不安定になったことです。千葉県内では夕方以降、線状降水帯が相次いで発生しました。発達した積乱雲が列をなして同じ場所を通り続ける、あの現象です。

被害も広がっています。各地で道路の冠水が相次いで車の立往生や車内への閉じ込めが起きています。
住宅の浸水や停電が発生している地域もあり、市川市ではがけ崩れが発生しています。
首都圏のJRや私鉄各線で運転見合わせや遅れが出ていて、千葉県が帰宅困難者向けに開放した県庁の庁舎には200人以上が身を寄せているそうです。

専門家は、下水道などの排水能力を超えて水があふれる内水氾濫の発生を指摘しています。夜間も危険な状態が続く見通しです。

気象庁は、14日夜遅くまでの24時間に降る雨の量が千葉県で多いところ200ミリ、千葉県以外の関東南部で180ミリ、関東北部で120ミリと予想しています。川の氾濫や浸水、土砂災害などへの警戒がまだまだ必要そうです。

## 追記：2026-08-14 08:00時点

一夜明けました。気象庁は14日5時39分に、千葉県22市町に出していたレベル5大雨特別警報をレベル4大雨危険警報やレベル3大雨警報などに、6市に出していたレベル5土砂災害特別警報をレベル4土砂災害危険警報に切り替えています。

千葉市中央区にあるアメダス千葉の記録は、次の通りです。1966年の統計開始以来の1位を、いずれも大きく上回りました。

このうち中央区市場町の千葉県庁では、約1800人が一夜を明かしました。

千葉市の浸水被害で報じられているのは次のような状況です。

## 追記：8月15日時点の道路の状況

雨が止んで道路の水も大半が引いていますが、路上には動けなくなった車が多数置かれたままになっています。

自宅周辺でも数十台がレッカー移動を待って止められているので、そばを通るのが正直なところ危ない状態です。

千葉市全体での放置車両の台数は、道路の管理者ごとに次のように把握されています。

| 道路の管理者                 |                           放置車両 |
| :--------------------------- | ---------------------------------: |
| 千葉市が管理する道路         | 約1000台（うち通行に支障 約270台） |
| 千葉県が管理する県道・国道   |     215台（15日までに142台を移動） |
| 千葉国道事務所が管理する国道 |            約100台（15日昼の時点） |

千葉国道事務所ですら「直轄する国道7路線すべてで実数を把握するのは難しい」としていますから、実際にはもっと多くの車が路上に置かれているでしょう。

移動作業は、所有者がレッカーを手配しているケースも多いと思いますが、災害対策基本法第76条の6にもとづく区間指定という枠組みで進められているようです。所有者の手配を待たずに、道路管理者が緊急通行車両の通行スペースを確保するために車を動かせる仕組みです。千葉県と千葉市は14日午前8時に管理道路を指定し、千葉国道事務所も15日19時15分に国道6号、14号、16号、51号、357号の広い区間を指定しました。同事務所が災害対応でこれだけ広範囲を指定したのは初めてだそうです。

JAFには13日夜から15日昼までに約2000件のレッカー要請が寄せられました。
お盆のため整備工場休業な上に台数も多い為民間レッカー業者にも依頼が殺到しており、ほぼ限界を超えているようです。路上の車には、撤去が21日以降になる見込みと書いた貼り紙が付いているものもあります。

中央区中央4丁目では約100メートルの区間に10台ほどが残り、片側2車線のうち1車線しか走れなくなっています。15日早朝には稲毛区の国道16号で、60代の男性の運転する乗用車が路上の放置車両に追突し、ほかの放置車両2台を含む4台による玉突き事故になりました。
千葉市はこうした追突事故を受けて、撤去に時間がかかる車には安全テープを貼って注意を促す対策を始めました。

しばらくは、見通しの悪い場所や夜間の運転では、路上に車が止まっている前提で走るくらいでちょうどよさそうです。
