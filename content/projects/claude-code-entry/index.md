非エンジニアを対象としたClaude Code入門の
セルフハンズオン教材です。
WebサイトリニューアルのRFP（提案依頼書）を
題材に、エージェント型AIとの協業を
5つの工程で体験します。

構想・仕様・執筆・校正・リリースの各工程で、
Claude Codeにどう指示し、どう情報を共有し、
どう成果物を仕上げるかを学びます。
「生成AIに丸投げする」のではなく
「工程を踏んで人間が主導する」ことが
ポイントです。

プログラミング経験は不要です。
Windows PC・Git Bash・VS Code環境で、
約3時間40分で一通り完了できます。
Marpスライド形式のHTML教材を
Releasesページからダウンロードして
すぐに始められます。
