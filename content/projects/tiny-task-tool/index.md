A digital sheet of paper for people tired
of over-engineered todo apps.
Jot down what's on your mind in the terminal
and get back to work immediately.

The command is `ttt`.
It runs as a TUI where you can add, complete,
and delete tasks with minimal keystrokes.
Inside a Git repository, tasks are
automatically scoped per branch.

## Install

```bash
brew install yostos/tap/ttt
```
